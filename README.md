# Microatividade 2 - Desenvolvimento de Funcionalidades Básicas em Software 🚀

Bem-vindo ao repositório **Microatividade 2**! Este projeto foca na construção de funcionalidades simples, ampliando o entendimento sobre lógica de programação e a implementação de operações básicas em sistemas interativos.

## ✨ Funcionalidades
- **Entrada de Dados**: Coleta de informações do usuário por meio de prompts.
- **Processamento e Exibição**: Manipulação dos dados inseridos e exibição do resultado.
- **Estruturas Condicionais**: Implementação de lógica básica utilizando condições para exibir diferentes respostas.

## 🚀 Tecnologias Utilizadas
- **Python** (linguagem de programação principal)
- **Terminal** (para interação com o usuário)

🌟 Sobre o Projeto
A Microatividade 2 é uma evolução da Microatividade 1, agora introduzindo funcionalidades mais complexas e interativas, utilizando lógica condicional e manipulando dados do usuário.

Contribuições e melhorias são sempre bem-vindas!
